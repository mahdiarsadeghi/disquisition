# Dissertation materials

This repository contains the dissertation source and supporting materials for work on mathematical modeling, control, and biological systems, including immunotherapy applications. The source is organized as LaTeX projects with the defense, main text, and proposal kept in separate directories.

## Repository map

- `maintext/` — dissertation chapters and supporting source files
- `defense/` — presentation and defense materials
- `proposal/` — proposal drafts and related documents

## Working with the source

Use a LaTeX toolchain that supports the packages referenced by the project. Build from the directory for the document you want to compile, and keep generated files out of version control; the repository `.gitignore` covers common editor and LaTeX outputs.

A rendered version of the project is available at [awesomedissertation.netlify.app](https://awesomedissertation.netlify.app/).
